# Prenota — bootstrap

## Cosa devo fare
API per prenotare i corsi di uno studio fitness.
Gli iscritti prenotano e cancellano. Lo staff gestisce corsi e capienza.

## Vincoli
- Node + TypeScript, database Postgres
- Cancellazione gratuita fino a 12 ore prima
- Lista d'attesa quando il corso è pieno
- Picchi di prenotazioni il lunedì alle 7:00, quando si aprono i corsi della settimana
