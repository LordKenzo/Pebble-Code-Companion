# Roadmap

1. Preparare il progetto: npm init -y, TypeScript e Vitest installati, un test finto che passa con npm test.
2. Definire in domain i tipi Cliente e Contatto e la regola "nome obbligatorio", con i test (anche per il nome vuoto).
3. Aggiungere la regola sui tag (spazi tolti, minuscolo, niente doppioni) con i test.
4. Creare il database SQLite in storage: tabelle e funzioni per salvare un cliente con il suo contatto.
5. Aggiungere le ricerche per nome, per tag e per prodotto.
6. Avviare il server Express con le richieste per aggiungere e cercare.
7. Costruire la pagina in public: modulo per inserire un contatto e una casella di ricerca.
8. Messaggi di errore chiari nella pagina e copia di sicurezza del file in data/.
